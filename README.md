
# End-to-End Sales Analytics & Revenue Prediction

## Project Overview
An end-to-end data analytics and machine learning project that analyzes sales transactions, evaluates business performance, and forecasts future monthly revenue.

The project uses a synthetic sales dataset to demonstrate data cleaning, exploratory data analysis, SQL analytics, machine learning, and interactive dashboard development.

## Objectives
- Analyze sales revenue and profitability.
- Identify product, category, and regional performance.
- Study historical monthly revenue trends.
- Build and evaluate a monthly revenue forecasting model.
- Present insights through an interactive dashboard.

## Technology Stack
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Plotly
- DuckDB (SQL analytics)
- Scikit-learn
- Streamlit
- Joblib
- Jupyter Notebook

## Key Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- SQL-based business analysis
- Revenue, profit, order, and customer KPIs
- Interactive product and region filters
- Interactive charts and transaction tables
- Revenue forecasting using Random Forest
- Comparison with a seasonal-naive baseline
- CSV export for filtered sales and forecasts

## Setup Instructions

### 1. Clone the repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd SalesAnalyticsRevenuePrediction
```

### 2. Create a virtual environment
```bash
python -m venv venv
```

Activate it on Windows PowerShell:
```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Generate the dataset
```bash
python create_dataset.py
```

### 5. Clean the data
```bash
python src/data_preprocessing.py
```

### 6. Run SQL analysis
```bash
python src/sql_analysis.py
```

### 7. Train the forecasting model
```bash
python src/revenue_forecasting.py
```

### 8. Launch the dashboard
```bash
python -m streamlit run app.py
```

## Model Evaluation
The forecasting model is evaluated on the final 12 months of historical data using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

Its performance is compared with a seasonal-naive baseline that uses revenue from the same month in the previous year.

Actual evaluation results are generated by running the forecasting script.

## Dataset
The project uses a synthetically generated sales dataset for demonstration and educational purposes. Its patterns and forecasts should not be interpreted as actual business results.
